A simple Python shopping cart system that allows users to buy items, calculate totals, and apply discounts based on purchase amount.
# Python Cart System With Discounts

A beginner-friendly Python project that simulates a shopping cart with billing and discount calculation.

## Features
- Display available grocery items
- Add items to cart
- Calculate total bill
- Apply discounts on purchases
- Menu-driven console application

## Technologies Used
- Python 3

## Available Items
- Milk
- Bread
- Rice
- Sugar
- Eggs
- Oil
- Soap
- Shampoo
- Biscuits
- Tea Powder

## How It Works
The program:
1. Displays available products with prices
2. Allows users to select items and quantity
3. Calculates item-wise bill
4. Adds items to cart
5. Calculates total amount with discounts

## Concepts Used
- Dictionaries
- Lists
- Loops
- Arithmetic operations
- User input handling
